# Negotiation visual evidence

Synthetic gallery only. Captures and machine results are generated by
`tools/run_gallery_negotiation_qa.cjs` and `tools/qa_gallery_negotiation.js`
using Playwright's installed Chrome channel (headless).
No real corpus data, mapping application or independent approval is implied.

The frozen report example is never modified. The populated gallery fixture is
explicitly synthetic and is not valid authority for applying a decision to a corpus.

See [the execution record](../../mode-negotiation-surface.md) for results,
contract gaps and verification limits. The 19 PNGs are viewport captures of a
scrolling region, not full-document snapshots; choice captures at narrow widths
frame the folder controls. `confirmation-900` and `capability-disabled` deliberately
overlap because mapping/undo are disabled throughout the confirmation flow.
